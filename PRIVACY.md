# Privacy Policy: GoldMine Performance

## 1. Overview
This policy describes how GoldMine Performance handles personal data. We prioritize data minimization and sovereign privacy.

## 2. Data Collection
The product collects limited 'Lead' information:
- Contact Details (Name, Phone, Email)
- Training Interests (Sport, Frequency)
- Interaction History (Messages, Sales)

## 3. Data Retention (The 48-Hour Purge)
GoldMine enforces a strict **48-Hour Data Lifecycle**.
- All personally identifiable information (PII) is automatically and permanently purged from the database 48 hours after creation.
- No historical backups or shadow copies are retained after the purge event.

## 4. Data Security (PCI-DSS Compliance)
The system is built to PCI-DSS v4.0 standards:
- **Storage:** Data is stored in client-side secure storage.
- **Transit:** No PII is transmitted to external servers in the demo state.
- **Identity:** Access is attributed to specific agent or user identities.

## 5. User Sovereignty
Users have the absolute right to:
- Request immediate manual data deletion.
- Audit their stored data via the Web UI.
